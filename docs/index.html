SentinelWatch

AI-powered desktop process monitor. Add this page to your home screen for one-tap access to downloads, docs and release notes.

On iPhone/iPad: tap the Share icon in Safari, then "Add to Home Screen".

● Desktop app — Windows / macOS / Linux

What this shortcut is

SentinelWatch is an Electron desktop application. It reads live process data and can terminate processes on your computer's operating system — capabilities a phone browser cannot grant to any web page. Installing this page gives you a home-screen icon that links straight back here for downloads and docs; it does not run the process monitor itself on your phone.

Features

  • Live process table updated every 5 seconds — CPU%, memory, accumulated CPU time, user
  • Hang detection: flags processes stuck above 10% CPU for 10+ minutes
  • One-click AI diagnosis powered by Groq
  • Filter, search and sort the process list; kill processes with confirmation
